# Лаба 1
## Описание
- Запустить контейнер и настроить подключение к БД
- Создать нормализованную структуру БД для данных, пример которых указан в **ships-data.json**
- Созданная структура должна уметь хранить данные перемещения судов в ретроспективе
- Занести данные из **ships-data.json** в созданную БД.
- Создать: 
    - Первичные ключи
    - Ограничения (ключи) ссылочной целостности
    - Ограничения null or not null
    - Ограничения непротиворечивости (проверки на заданные значения или диапазон значений) 
- Реализовать различные варианты удаления зависимых сущностей (каскадные удаления, триггеры).
- Построить ER-диаграмму
- Подготовить дамп БД

## Конечный результат

- Скрипт **init.sql** для создания базы данных
- Обновленный **docker-compose.yml**
- Скрипт на python для загрузки данных из **JSON** в БД
- ER диаграмма из **DBevear**  

## Что нужно сделать в процессе

1. Разбить данные из JSON на различные сущности
2. Нормализовать полученные сущности до **НФБК**
3. Добавить ограничения, проверки
4. Продумать и прописать варианты удалениия сущностей
5. Сделать **ER диаграмму**
6. Написать скрипт, который перености данные из JSON в БД и перенести данные
7. Проветси тесты и проверки на ограничения и непротиворечивости
8. Если все сделано правильно, то подготовить итоговые файлы и загрузить лабу
